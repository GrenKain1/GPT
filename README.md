# FantasyDream

Сайт-каталог матрасов: иврит (основной, RTL), русский и английский. Английская админка, файловый PHP-движок без SQL, заявки по электронной почте и WhatsApp. В каталоге 8 моделей и 128 размеров с ценами из предоставленных PDF.

Сейчас проект находится на этапе просмотра и правок. Финальный дистрибутив для Apache будет подготовлен после согласования оформления и контента.

## Просмотр

Папка `docs/` содержит HTML-версию для GitHub Pages. Она показывает главную, каталог, карточки, контакты и демонстрацию английской админки. На GitHub Pages PHP не выполняется: заявки не отправляются, а изменения в демонстрации админки не сохраняются. На Apache эти функции работают через серверную часть.

В GitHub откройте **Settings → Pages** и выберите **GitHub Actions**, если Pages ещё не активирован. Workflow **Deploy design preview** публикует только папку `docs/`. Реальные настройки, сессии и пароли в неё не входят. Возможность Pages для закрытого репозитория зависит от тарифа GitHub; видимость репозитория автоматически не меняется.

Обновление предпросмотра после правок: `python3 tools/build_preview.py --php /путь/к/php`. Затем проверяйте изменения, коммитьте исходники и папку `docs/`.

## Исходники

- `public_html/` — публичные PHP-страницы, готовые CSS/JS и изображения.
- `private/` — движок, начальный каталог и тексты на трёх языках; на хостинге папка находится вне публичного корня.
- `tests/` — проверки авторизации, файлов, SMTP, адаптивности и доступности.
- `tools/` — генерация предпросмотра и будущего дистрибутива.

Каталог, цены и описания доступны в `private/catalog.php`; главная и исходные контакты — в `private/defaults.php`; подписи интерфейса — в `private/translations.php`. В рабочем сайте администратор редактирует эти данные через формы, они сохраняются в приватный `content.json`.

Неизвестные адрес, часы работы, номер WhatsApp, НДС и условия доставки оставлены для последующего заполнения. Неоднозначные сведения из PDF перечислены в [CATALOG-NOTES.ru.md](CATALOG-NOTES.ru.md).

## Проверки

PHP 8.2+, Python 3 и Node.js используются для разработки и проверок; сборка на рабочем хостинге не нужна.

```sh
python3 tests/smoke.py --php /путь/к/php --browser
python3 tools/build_preview.py --php /путь/к/php
```

Тесты используют временные копии и локальный SMTP. Они не меняют рабочие данные и не отправляют письма покупателям. Каждая облачная задача уже изолирована; используйте существующий checkout, без создания Git worktree.
